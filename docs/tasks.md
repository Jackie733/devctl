## 当前任务：两行底栏与日志整行选择复制，待用户审核

- 起点为 b5cc1e1，工作区干净。用户反馈底部三行占用空间，确认先支持整行与多行复制；主要终端为 Windows Terminal 中的 WSL2，同时考虑 Linux、macOS。关联 M5、U01、L01、L03；助手继续直接编写、验证、提交，用户最后审核。
- 主界面底部固定两行：异常标记/项目错误摘要/最近操作反馈一行，上下文快捷键一行；右侧保留帮助与离开。完整诊断和更多键位保留在帮助，主界面不因错误增加底栏高度。
- 日志按 V 选中第一条可见记录；j/k 扩展，gg/G 及翻页移动端点；行高亮和 > 标记端点，无字符级光标。y 发送正文，Esc 取消并留在日志；选择模式不穿透面板与服务控制键，帮助不穿透复制键，q/Ctrl-C 仍只离开客户端。
- 选区只存序号，不另存日志副本；新增输出不移动阅读位置或选区。淘汰任一端点就取消并告警；项目/后台切换和断连清除选区。复制按日志顺序包含完整缓存正文与换行，排除 UI 前缀/填充；截断记录带标记；64 KiB 上限拒绝部分发送。
- 复用 Crossterm osc52 feature，新增其 base64 0.22.1 可选依赖并更新锁文件；首次普通沙箱解包因 Cargo 缓存只读失败，沙箱外 cargo check --locked --offline 解包缓存并编译通过，未使用网络下载。只向终端发送，不读剪贴板、不调用平台专用程序。
- 当前规则见 [interaction.md](interaction.md) §2.3–§2.5，状态/预算与职责见 [DESIGN.md](../DESIGN.md) §5.2；已同步需求 L01 与 README。日志搜索、重启、字符选择和命令行模式未纳入本轮。
